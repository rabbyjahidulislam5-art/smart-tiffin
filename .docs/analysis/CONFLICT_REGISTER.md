## Intentional changes vs accidental omissions

An item missing from the new tree that existed before is **accidental** unless listed here, in the [requirements change log](REQUIREMENTS_CHANGE_LOG.md) or in the [obsolete document review](OBSOLETE_DOCUMENT_REVIEW.md). The final consistency audit checks each old FR/UC/AC/TEST/ADR/screen/control identifier against the new tree.
